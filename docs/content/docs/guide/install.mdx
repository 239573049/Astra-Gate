## 系统要求

- Node.js **≥ 18**（通过 npm 安装 CLI 时需要）
- macOS / Linux / Windows

## 一键安装脚本（无需 Node.js）

macOS / Linux：

```bash
curl -fsSL https://astra-gate.si/install.sh | bash
```

Windows（PowerShell）：

```powershell
iwr https://astra-gate.si/install.ps1 -UseBasicParsing | iex
```

脚本会询问安装**服务端**（`astra-server` + 网页控制台）还是**桌面端**（已内置服务端），直接回车默认装服务端。也可以提前指定，免去提问：

```bash
curl -fsSL https://astra-gate.si/install.sh | bash -s -- --desktop
```

```powershell
$env:ASTRA_INSTALL = 'desktop'; iwr https://astra-gate.si/install.ps1 -UseBasicParsing | iex
```

服务端装在 `~/.astra/server/`，并在 `~/.local/bin`（Windows 为 `%USERPROFILE%\.astra\bin`）放一个 `astra-server` 启动命令；运行 `astra-server serve` 即可。所有下载都会先校验发布源里的 sha256，不一致就不会安装。再次运行脚本即可更新。

脚本安装的只有 `astra-server`，不含 `astra` 命令行工具；需要 `astra` 命令请用下面的 npm 方式。

## 安装 CLI

```bash
npm install -g @aidotnet/astra-gate
```

`astragate` 是同一个包的另一个名字（`npm install -g astragate` 效果相同），二者装出的都是 `astra` 命令，选一个即可，不要同时全局安装。

安装包会按当前平台自动选择对应的 `@aidotnet/server-*` 二进制（darwin/linux/win32 × arm64/x64），不需要单独安装 .NET 运行时。

安装完成后验证：

```bash
astra --version
```

<Callout type="idea" title="不想全局安装？">
  也可以用 `npx @aidotnet/astra-gate <命令>` 直接运行，效果相同。
</Callout>

## 安装桌面端（可选）

桌面端是一个 Electron 壳，把控制台包成了独立应用，并支持菜单栏快捷操作与开机自启。

不想装 Node.js 的话，直接从[下载页](/download)下载安装包（macOS `.dmg` / Windows `.exe` / Linux `AppImage`），安装包内置服务端。

也可以通过 npm 安装，不需要全局安装 CLI，一条命令即可：

```bash
npx @aidotnet/astra-gate install --desktop
```

已全局安装 CLI 的话，等价于：

```bash
astra install --desktop
```

通过 npx 安装时，服务端二进制会被复制到 `~/.astra/server/`，桌面端不依赖 npx 缓存。详见[桌面端](/docs/desktop)。

## 数据放在哪里

Astra 的所有状态都在 `~/.astra`（可用环境变量 `ASTRA_HOME` 覆盖）：

| 路径 | 内容 |
| --- | --- |
| `~/.astra/config.json` | 启动配置（端口、监听地址等） |
| `~/.astra/runtime.json` | 实际运行状态（pid / 端口 / apiVersion） |
| `~/.astra/astra.db` | SQLite 数据库（请求记录、模型、提供商、设置） |
| `~/.astra/server/` | 托管的服务端二进制与界面资源（`astra update` 或 npx 安装桌面端时写入） |
| `~/.astra/keys/` | 加密密钥（权限已限制为当前用户） |
| `~/.astra/logs/` | 服务日志 |
| `~/.astra/backups/client-configs/` | 接管客户端前的配置备份 |

## 升级与卸载

```bash
astra update            # 更新 CLI（及已装的桌面端），然后重启服务
astra uninstall         # 停止服务并还原所有被接管的客户端配置
astra uninstall --purge # 连 ~/.astra 数据目录一起删除
```

<Callout type="warn" title="卸载前会自动还原">
  `astra uninstall` 会先用 `restore-all` 的逻辑把每个被接管客户端的配置恢复为启用前的样子，再停止服务——
  客户端不会因为 Astra 卸载而失联。
</Callout>

## 预览版

正式版的版本号形如 `0.10.0`；预览版形如 `0.10.0-preview.1`，提前提供下一个正式版的新功能，供愿意尝鲜的用户试用和反馈，可能不稳定。**默认只接收正式版**，预览版需要自己开启：

- **接收预览版更新**：控制台 **设置 → 关于** 打开「接收预览版更新」。之后服务端的更新检查、桌面端（含 macOS 安装包的应用内更新）和 `astra update` 都会提供预览版；正式版发布后同样会更新上去。
- **直接安装预览版**：安装脚本加 `--preview`（Windows 设置 `$env:ASTRA_CHANNEL = 'preview'`），或在[下载页](/download)展开「预览版」；npm 用户可以 `npm install -g @aidotnet/astra-gate@preview`；Docker 镜像使用 `:preview` 标签。

```bash
curl -fsSL https://astra-gate.si/install.sh | bash -s -- --preview
astra update --channel preview   # 只这一次按预览版更新，不改设置
```

关闭「接收预览版更新」**不会降级**：已经装了预览版的话，会停在当前版本，直到发布了比它更新的正式版（例如 `0.10.0-preview.3` 之后的 `0.10.0`）。服务未运行时 `astra update` 读不到这个设置，按正式版处理，需要时加 `--channel preview`。
