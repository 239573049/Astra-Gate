title: 第一个请求
description: 启动服务、添加提供商，用任意协议发出第一条请求
---

本页带你走通最小闭环：**启动服务 → 添加提供商 → 发请求 → 看日志**。控制台里每一步的截图见[管理控制台](/docs/console)。

## 1. 启动服务

```bash
astra start
```

默认后台运行，监听 `127.0.0.1:17321`。常用变体：

```bash
astra start --open            # 启动后打开控制台
astra start --port 18000      # 换端口
astra start --foreground      # 前台运行（看日志排错）
```

确认状态：

```bash
astra status
```

<Callout title="端口可能变化">
  如果 17321 被占用，Astra 会自动换一个可用端口，并把**实际端口**写进 `~/.astra/runtime.json`。
  控制台与 CLI 始终读取真实端口，脚本里不要写死 17321。
</Callout>

## 2. 添加一个提供商

打开控制台（`astra open`，或桌面端直接启动），进入 **提供商** 页：

1. 点击右上角 **添加提供商**；
2. 从模板中选择服务商（Anthropic / OpenAI / DeepSeek / OpenRouter…，或「自定义提供商」接入任意兼容接口）；
3. 填入 API Key（加密保存在本机 `~/.astra/keys`），保存；
4. 点 **测试连接**，显示「连接正常」即可。

详细截图：[提供商页教程](/docs/console/providers)。

## 3. 发出请求

网关对三种主流协议都开放了兼容端点，把客户端的 base URL 指向 Astra 即可：

<Tabs items={['OpenAI 兼容', 'Anthropic 兼容', 'Gemini 兼容']}>
  <Tab>
    ```bash
    curl http://127.0.0.1:17321/v1/chat/completions \
      -H "Content-Type: application/json" \
      -d '{
        "model": "deepseek-chat",
        "messages": [{ "role": "user", "content": "你好，Astra" }]
      }'
    ```
  </Tab>
  <Tab>
    ```bash
    curl http://127.0.0.1:17321/anthropic/v1/messages \
      -H "Content-Type: application/json" \
      -d '{
        "model": "claude-sonnet-4-5",
        "max_tokens": 1024,
        "messages": [{ "role": "user", "content": "你好，Astra" }]
      }'
    ```
  </Tab>
  <Tab>
    ```bash
    curl "http://127.0.0.1:17321/gemini/v1beta/models/gemini-2.5-pro:generateContent" \
      -H "Content-Type: application/json" \
      -d '{
        "contents": [{ "parts": [{ "text": "你好，Astra" }] }]
      }'
    ```
  </Tab>
</Tabs>

请求里的模型名只要存在于模型目录（或在某个提供商下添加过），Astra 就会路由到对应的上游，并在协议不一致时自动转换。

## 4. 查看结果

- **概览** 页出现费用、请求数、token 统计与趋势图；
- **请求日志** 页可以点开这条请求，查看逐项计费（输入 / 缓存命中 / 缓存写入 / 输出）、耗时与请求体；
- 如果配置了隐私护栏且命中敏感信息，请求详情会标注「已脱敏 N 处」或「已拦截」。

## 5. 接管一个客户端（可选但推荐）

与其让客户端直接配 base URL，不如让 Astra 代管：

<Screenshot src="/screenshots/clients.png" alt="客户端页面：Codex 与 Claude Code 已启用，其余客户端可一键启用" title="Astra — 客户端" caption="客户端页：一键启用 / 禁用并还原" />

在 **客户端** 页点「启用…」，Astra 会把网关地址与本地密钥写进客户端配置（首次修改前自动备份原文件）。之后切换提供商、切换模型都在控制台完成，客户端无需再动。详见[客户端教程](/docs/console/clients)。
