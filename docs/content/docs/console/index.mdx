管理控制台是 Astra 的可视化界面：概览统计、提供商与模型管理、客户端接管、请求日志、隐私护栏和设置都在这里完成。

## 打开方式

| 方式 | 操作 |
| --- | --- |
| 桌面端 | 启动 Astra 桌面应用即是控制台（推荐） |
| 浏览器 | 运行 `astra open`，或访问 `http://127.0.0.1:17321`（以 `runtime.json` 中的实际端口为准） |
| 启动时打开 | `astra start --open` |

## 登录

本机访问**免密码**。把服务监听到局域网（[设置 → 网关 → 监听](/docs/console/settings#局域网访问)选「局域网」，或 `astra start --host 0.0.0.0`，都需要先设置管理员密码）后，**其他设备**打开控制台要求登录：

<Screenshot src="/screenshots/login.png" alt="登录页：居中的玻璃卡片，提示输入管理密码" title="Astra — 登录" caption="对外监听时的登录页；环回访问无需登录" />

<Callout type="warn" title="安全边界">
  即使在本机，所有「修改」类接口也要求请求头 `X-Astra-Admin: 1`（Web 控制台已自动携带）。
  对外监听时，只有从本机回环地址连入、Host 为 `127.0.0.1` / `localhost`、且没有代理转发头（`X-Forwarded-For` 等）的请求才算本机；
  其余请求都要会话 cookie，调用网关必须带令牌。不要把端口暴露到不受信任的网络。
</Callout>

## 界面布局

左侧是玻璃质感的侧边栏，底部常驻服务状态卡（绿点 + 实际监听地址）：

- **概览 / 请求日志** — 统计与明细
- **配置**：客户端、提供商、模型、隐私护栏、智能路由
- **系统**：设置

右侧内容区随页面切换，后续章节逐页讲解。
