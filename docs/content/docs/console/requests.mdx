每一笔经过 Astra 的请求都记录在请求日志：谁发的、用了什么模型、路由到哪个提供商、花了多少钱、隐私护栏有没有拦。

## 筛选

- **搜索** — 按模型 ID 关键字过滤；
- **客户端 / 令牌 / 提供商 / 状态** — 四个多选下拉，可同时选多个值，不选表示不限；
- **来源** — 只在开启过[远程访问](/docs/guide/remote-access)后出现，按「远程 / 本机」筛选；
- 有筛选生效时可以一键清空；顶部「共 N 条」始终是筛选后的总数；
- 筛选条件会写进地址栏，例如 `/requests?token=<令牌 ID>&status=upstream_error,gateway_error&model=gpt`，可以收藏、刷新或分享；令牌页的「查看日志」就是这样打开的。可用的参数是 `client`、`token`、`provider`、`status`、`origin`（多个值用逗号分隔）和 `model`。

**状态** 取值：

| 状态 | 含义 |
| --- | --- |
| 成功 | 正常返回。客户端收到完整答案后断开也算成功（例如收到 `[DONE]` / `response.completed` 就断开，而上游还没关闭连接） |
| 已拦截 | 被隐私护栏拒绝，未发往上游 |
| 上游错误 | 上游返回错误（Key 失效、额度不足、限流、服务过载…），包括流式过程中上游发来的错误事件；详情里显示上游的原始错误信息 |
| 网关错误 | Astra 自身出错 |
| 已取消 | 客户端在答案结束前断开；发往上游的请求随之取消，已产生的用量照常计费 |

表格里每一行都能直接读出关键信息：网关换过模型时（Claude Desktop 角色映射或提供商模型映射），模型名后面会跟「→ 实际发给上游的模型」；模型名下方是「返回模型 + 一致性」（API 返回的模型与上游发送模型对照，悬停可看请求 / 上游发送 / API 返回三者；请求进行中显示「等待中」），还有 TTFT / 输出速度、输入 / 输出（含推理）与缓存命中 / 写入。请求的是[智能路由](/docs/console/smart-routing)的虚拟模型时，模型名旁边还有「智能路由」标记：绿色是按判定分配，橙色是没按判定走（回退档位，或者判定的档位调用方用不到、改用了别的档位），悬停可看原因和发往的模型，详情里有完整的判定结果。

## 请求详情

<Screenshot src="/screenshots/request-detail.png" alt="请求详情：概要、耗时、Token 用量与计费" title="Astra — 请求详情" caption="详情弹层：概要 + 耗时 + Token 用量 + 计费" />

### 概要与耗时

协议、是否流式、`service_tier`、**请求模型 / 上游发送模型 / API 返回模型** 三者对照（映射或别名时可能不同；API 返回模型旁边的「一致 / 不一致」比较的是它和上游发送模型，所以映射本身不算不一致，上游换了模型才算）、TTFB / TTFT / 生成耗时 / 总耗时、**输出速度**（tok/s）。TTFT / 生成耗时 / 输出速度从流式到达的首 token 起算；非流式请求没有首 token 时刻，这三项显示「—」而不猜测。上游先攒完整个回答、等响应头才发出、再把输出一次性回放时（响应头的等待比其后的全部内容还长，且输出在远快于 1000 tok/s 的时间内到齐），回放那一瞬间算不出真实速度：生成耗时和输出速度同样显示「—」，TTFT 仍是客户端真实看到首 token 的时间。

### Token 用量

输入总量、输出总量、缓存命中率与推理 token 四个数字，下方用堆叠条形图拆出未缓存输入 / 缓存命中 / 缓存写入与非推理输出 / 推理的构成。

### 计费

费用总额与逐项表格：普通输入、缓存写入（5m / 1h）、缓存命中、推理、输出——每项的数量、单价（USD / 1M）、档位与费用。右上角徽标标注**价格来源**（官方默认价 / 提供商价格表 / 提供商自定义价）。上游未返回 usage 时该请求记为 0，并在详情中说明。

### 请求体

开启「保存请求与响应内容」（见[设置](/docs/console/settings)）后，详情底部还会出现四个标签页：**客户端请求体 → 上游请求体 → 上游响应体 → 返回客户端的响应体**，可直观对比协议转换与隐私脱敏前后的差异。

每部分最多保存 8 MB。超过 64 KB 的请求体在详情里只显示开头部分，点「加载全部」再读取完整内容（以纯文本显示，不做格式化）。

<Callout type="info" title="默认不保存请求体">
  出于隐私考虑，请求体内容默认不落盘。打开开关后才开始保存（存在本机数据目录、不含密钥，
  并可设自动清理期限）。
</Callout>
