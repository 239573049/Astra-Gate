title: 客户端

「接管」是 Astra 的核心体验：不用手工编辑客户端配置文件，控制台里点一下即可把客户端指向网关，随时可还原。

## 每个客户端一个标签页

<Screenshot src="/screenshots/clients.png" alt="客户端页：顶部是客户端标签，下方是 Codex 的接管卡片" title="Astra — 客户端" caption="客户端页：Codex 已启用并绑定 DeepSeek" />

页面顶部是本机检测到的客户端标签（启用过的带 ✓）。选中某个客户端后，下方是它的接管卡片：

- **状态行** — 「已启用」徽标 + 已写入的配置文件路径；右侧 **禁用并还原**；下方是最近一次写入配置的时间；
- **使用的提供商** — 单选卡片，切换后**立即生效**，不需要修改客户端配置文件；
- **模型** — 启用时写入客户端配置的默认模型（修改后需要重新写入客户端配置）；
- **维护** — 复制配置文件路径、配置备份、轮换本地密钥。

支持的客户端：Codex、Claude Code、Gemini CLI、OpenCode、Claude Desktop，以及即将支持的 Grok Build。

## 启用

<Screenshot src="/screenshots/client-detail.png" alt="未启用的客户端标签页，展示启用按钮" title="Astra — 客户端" caption="未启用的客户端：点「启用…」由 Astra 代写配置" />

切换到一个未启用的客户端标签，点 **启用…**，Astra 会：

1. 展示将要写入的改动清单（只新增 / 修改 Astra 自己的配置项）；
2. **首次修改前备份原文件**（这份备份永久保留）；
3. 写入网关地址与本地访问密钥。

启用后客户端需要重启一次使配置生效；之后切换提供商、模型都在控制台完成，客户端无需再动。

## 维护

| 项 | 说明 |
| --- | --- |
| **复制配置文件路径** | 快速定位 Astra 代管的客户端配置文件 |
| **配置备份** | 每次修改前自动备份，可随时恢复；首次修改前的备份永久保留，另有约 20 份滚动备份 |
| **轮换本地密钥** | 生成新的本地访问密钥并写入客户端配置，旧密钥立即失效 |

<Callout type="info" title="Claude Desktop 与角色映射">
  Claude Desktop 只认 Sonnet / Opus / Haiku 这类「角色模型」。Astra 会把它们映射到你选择的提供商模型
  （该客户端标签页里的「角色映射」分区），至少设置一个角色，未设置的角色沿用第一个已设置的。
</Callout>

## 禁用与还原

- **禁用并还原** — 撤销 Astra 写入的配置项，恢复到启用前的状态；
- 如果某些配置项在你启用后又被手动改过（「漂移」），Astra 不会擅自覆盖，会列出这些项并询问是否**强制还原**；
- 服务器已经卸载、控制台打不开？终端运行 `astra restore-all` 可以**离线**还原全部客户端配置（见 [CLI 参考](/docs/cli/clients)）。

<Callout type="warn" title="密钥安全">
  Astra 写入客户端的是一把**本地访问密钥**（不是上游 API Key）。它只对本机网关有效，
  可随时在「维护」里轮换，使其立即失效重发。
</Callout>
