概览页回答一个问题：「今天（或最近一段）用了多少」。右上角切换时间范围：**今日 / 7 天 / 30 天 / 90 天**，所有卡片和图表随之刷新；工具栏左侧的图标可以按客户端快速过滤（比如只看 Codex 的用量），旁边的下拉框可以只看某个令牌。

## 活跃度

页面顶部的热力图按天显示过去 365 天的请求数，颜色越深请求越多，悬停格子可看当天的具体次数；下方一行给出有活动的天数和单日峰值。它固定统计最近一年，不随右上角的时间范围变化，但会跟随客户端和令牌过滤。

## 指标卡

| 卡片 | 含义 |
| --- | --- |
| **总成本** | 时间范围内所有成功请求的计费总额（按模型单价逐项累加） |
| **总请求数** | 经过网关的请求总数 |
| **Token** | 输入 + 输出总量；卡片下方标注了输入 / 输出的拆分 |
| **缓存命中率** | 缓存命中 token ÷ 输入总量；下方是命中与写入量 |
| **成功率** | 状态为「成功」的请求占比 |
| **平均 TTFT** | 首 token 平均延迟（流式请求的体感指标） |

<Callout title="Token 口径">
  「输入总量」已包含缓存命中与缓存写入，「输出总量」已包含推理 token——两项不会重复相加。
  命中率 = 缓存读取 ÷ 输入总量。上游未返回用量的请求记为 0，不影响命中率以外的指标。
</Callout>

## 使用趋势

「使用趋势」卡片右上角可切换指标：**请求数 / Token / 费用**。

- 「今日」按小时分桶，其他范围按天分桶；
- 柱状图左侧显示每小时（或每天）平均值，右侧坐标轴辅助读数；
- 悬停柱子可看具体数值。

## 今日账单

右上角的 **生成账单** 一键生成当天的消费账单：按提供商分组，列出每个模型的请求数、输入 / 输出 Token 和费用，再给出小计与合计。账单有两种样式，在弹窗顶部切换，下次打开沿用上次的选择：

| 样式 | 说明 |
| --- | --- |
| **小票** | 热敏小票风格：等宽字体、锯齿撕边、按账单号生成的条形码 |
| **漫画** | 线稿漫画风格：Astra 头像配对话气泡（说出今天花了多少、哪家提供商占比最大）、网点纸合计栏和「已结算」印章 |

- 账单按你本机的时区切分「今天」，统计 0 点到生成那一刻；不受上方客户端、令牌过滤和时间范围的影响。
- 只统计路由到了某个提供商的请求：失败的请求也计入请求数和成功率（通常没有费用），在选出提供商之前就失败的请求不在账单里，所以合计等于各提供商之和。
- **复制图片** 把账单以 PNG 放进剪贴板，**保存 PNG** 存为 `astra-bill-<日期>-<样式>.png`（2 倍分辨率）。网页控制台和桌面客户端生成的账单内容与样式一致。
- 金额和概览卡片一样是按模型单价估算的，可能与提供商的实际账单存在差异。

## 明细入口

页面底部的卡片提供三个标签：**请求日志 / 提供商 / 模型**，直接在概览里翻看最近的请求明细，或按提供商、模型聚合；「查看全部」跳转到对应页面。想深挖某条请求，到[请求日志](/docs/console/requests)即可。

<Callout type="idea" title="还没有数据？">
  全新安装时概览页会给出网关地址提示（`http://127.0.0.1:17321/v1`）——把任意兼容客户端指过去，
  发一条请求后这里就会亮起来。
</Callout>
