模型页是 Astra 的**系统级模型目录**：每个模型的参数（上下文窗口、最大输出、能力）与官方默认价格都在这里。客户端请求什么模型名，以及「这 条请求值多少钱」，都以这个目录为准。

## 列表说明

- **搜索 / 全部厂商** — 按模型 ID 与别名模糊匹配，或按厂商过滤；
- **模型列** — 显示名称与模型 ID；行内还会出现来源与状态徽标（「已修改」表示该字段被手动改过，同步时不会覆盖）；
- **上下文** — 上下文窗口大小（如 200K、1M）；
- **输入 / 输出** — 官方默认价，单位 USD / 百万 tokens；
- **提供商价格** — 有多少提供商的价格表为该模型定义了专属价格（含时段规则、分档时会在详情中标出）。

## 三级价格体系

一条请求的费用按以下优先级取价：

1. **提供商自定义价格** — 在「提供商 → 模型」上显式覆盖的价格，完全替换继承价，**不乘**提供商倍率；
2. **提供商价格表** — 该提供商的价格表（如 `openrouter`）为模型定义的价格，**会乘**提供商的价格倍率；
3. **官方默认价** — 模型页里这份价格，兜底。

在模型详情里可以分别查看与编辑这三层，还有 **计费模拟器**：输入一次请求的 token 构成（普通输入 / 缓存读写 / 推理 / 输出）与 `service_tier`、请求时间，实时算出费用，用于核对价格配置。

## 同步 models.dev

点右上角 **同步 models.dev**，Astra 拉取最新的模型参数与价格：

<Callout type="info" title="不会覆盖你的修改">
  被你手动改过的字段标记为「已修改」，同步时自动跳过；同步前会先列出「新模型 / 价格变更 / 字段变更」清单，
  确认应用后才落库。
</Callout>

## 新建模型

上游没收录的模型（比如内部部署的模型）点 **新建模型** 手动登记：ID、显示名称、厂商、上下文窗口、最大输出与价格。之后就能在提供商里引用它，费用也会正常统计。
