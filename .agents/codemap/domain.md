# Domain concepts

The business nouns that appear in types, tables, routes and screens. Where a concept is defined, where it is
persisted, and where a user meets it.

| Concept | Definition | Defined in | Persisted in | Surfaces in | Related flows |
|---|---|---|---|---|---|
| Provider | An upstream AI service Astra can call. `AuthScheme` decides whether it uses one API key or a set of accounts. | `src/Astra.Core/Models/Provider.cs:Provider` | `providers` (+ `provider_models`) | `/api/providers`, console Providers page | gateway-request, provider-quota-refresh |
| Provider template | The versioned, shared defaults a provider inherits (endpoints, model list, headers, pricing policy); a provider is a merge of template and user overrides. | `src/Astra.Providers/Templates/ProviderTemplateCatalog.cs:ProviderTemplate` | built-in JSON, `providers.template_id`, `settings.template` | `/api/providers/templates` | gateway-request |
| Effective model | The model as actually used after provider override → template → system default, with `FieldOrigin` recording which layer won. | `src/Astra.Core/Models/EffectiveModel.cs:EffectiveModel`, `FieldOrigin` | `models`, `model_prices` (`seed` / `sync` / `user` source) | console Models page | gateway-request |
| Provider account | One credential of an account-based provider: an OAuth subscription sign-in or an API key. | `src/Astra.Core/Models/ProviderAccount.cs:ProviderAccount`, `AccountKinds`, `AccountStatus` | `provider_accounts` (`extra_json.quota`, `extra.quotaSync`, `extra.credits`) | console provider/accounts cards, subscription components | subscription-account-refresh, gateway-request |
| Subscription family | The unit a quota probe and OAuth config are keyed by: the provider *template id* (`claude-subscription`, `openai-subscription`, …). | `src/Astra.Providers/Subscription/SubscriptionOAuth.cs:SubscriptionOAuthConfig`; the same rule in gateway `SubscriptionSupport.ProviderKeyOf` | provider `template_id` | console account cards | subscription-account-refresh |
| Quota snapshot (API key) | What a provider's balance/plan probe returned: `{fetchedAtUtc, template, kind, isValid, planLabel, plans[]}`, plus merged failure fields. | `src/Astra.Providers/Quota/ProviderQuotaService.cs:ProviderQuotaService` | `providers.quota_json` | console quota section | provider-quota-refresh |
| Quota snapshot (account) | `{fetchedAtUtc, session, weekly, credits, planLabel}` for a subscription account. | `src/Astra.Providers/Subscription/SubscriptionQuotaService.cs:SubscriptionQuotaService` | `provider_accounts.extra_json.quota` | subscription account cards | subscription-account-refresh |
| Gateway token | The `sk-astra-…` credential a client presents; optionally carries budgets, an RPM cap, an allowed-client list and a provider pool for its direct calls. | `src/Astra.Core/Tokens/TokenRecord.cs:TokenRecord`, `TokenLimits.cs:TokenLimits`, `TokenPool.cs:TokenPool` | `tokens` (`limits_json`, `allowed_clients_json`, `pool_json`), counters in `token_usage_totals` / `token_usage_daily` | console Tokens page and token detail (`/tokens/:id`), self-service `/key` page | token-limits-enforcement, gateway-request |
| Provider pool | The providers a bare token's direct calls are spread over (failover / round robin / weighted / tiered / least busy), with sticky sessions and cross-provider failover before the reply starts. | `src/Astra.Core/Tokens/TokenPool.cs:TokenPool`; scheduling `src/Astra.Gateway/Pipeline/ProviderPoolScheduler.cs`, health `ProviderHealth.cs` | `tokens.pool_json` (first member mirrored in `provider_id` / `account_id`); health and bindings in memory | token settings sheet, token detail, trace request view | gateway-request, request-tracing |
| Client kind | Which AI client a request came from (Claude Code, Codex, …; plugin agents are `plugin-<id>`). Selects privacy defaults, options and routing. | `src/Astra.Core/Clients/ClientContracts.cs:ClientKinds` | `clients.clients_json`, request row `client_kind` | console Clients page | client-config-takeover, gateway-request |
| Client config state | The per-keyPath record of what Astra wrote into a client's config file, and what was there before — the basis of restore and drift detection. A strict-JSON repair records none of this. | `src/Astra.Core/Clients/ClientContracts.cs:ClientConfigStateEntry` | `client_config_state` + first-write files under `~/.astra/backups/client-configs/` | restore/disable in console and CLI | client-config-takeover |
| Client option | One client-specific setting (scope `config` = written into the client's file; scope `gateway` = read by the gateway per request). | `src/Astra.Core/Clients/ClientOptions.cs:ClientOptionDescriptor` | `clients.extra_json.options` | console client options group | client-config-takeover |
| Request record | One gateway request: protocol, model, status, tokens, cost in nanodollars, error type, privacy report, and where it sits in its agent's loop (session, turn, parent call, finish reason). | `src/Astra.Core/Requests/RequestRecord.cs:RequestRecord` | `requests` (+ `request_usage_items`; `request_attempts` is unused) | console Requests page, live feed | gateway-request, request-tracing |
| Trace span | One timed step of a gateway request (`gateway.request`, `gateway.route`, `gateway.body`, `gateway.middleware`, `gateway.privacy`, `gateway.resolve`, `gateway.encode`, `upstream.attempt`, `gateway.response`). | `src/Astra.Core/Requests/TraceSpan.cs:TraceSpan`, `:TraceSpanNames` | `trace_spans` (migration `0017_tracing.sql`, deleted with the request row) | console 链路追踪 (`/traces`), `GET /api/traces/**` | request-tracing |
| Agent turn | What Astra infers one user input and the model calls that follow it to be: a shared `trace_id` and `turn_id`, linked by tool-call id when it can and guessed otherwise. | `src/Astra.Gateway/Tracing/TraceLinker.cs:TraceLinker`, `TraceKeys` | the link columns on `requests`; the linker's memory is not persisted | the session and request canvases | request-tracing |
| Billing / price | What a request cost: `NormalizedUsage` counters priced by the resolved price, stored as integer nanodollars. | `src/Astra.Core/Billing/BillingEngine.cs:BillingEngine`, `PricingResolver.cs:PricingResolver` | `requests.cost_nanousd`, `model_prices` | console Requests/Billing views | gateway-request |
| Money | Integer nanodollars, 1e9 per USD; unit prices are decimal strings inside pricing JSON. Never a float. | `src/Astra.Core/Json.cs:Money` | every `*_nanousd` column | everywhere money is shown | gateway-request, token-limits-enforcement |
| Privacy policy | The effective per-request privacy decision: an action ladder rule → category → client default → default. | `src/Astra.Core/Privacy/PrivacyTypes.cs:EffectivePrivacyPolicy` | settings key `privacy` | console Privacy page | privacy-redaction |
| Redaction placeholder | `[REDACTED:<category>#n]`, unique per request body, restored in the response. | `src/Astra.Core/Privacy/PrivacyDetector.cs:PrivacyDetector.ApplyInto` | `requests.privacy_json` (placeholders and hit counts only — never originals) | console privacy event log | privacy-redaction |
| Alert rule | Event + conditions + scope + target webhooks; a webhook only delivers. | `src/Astra.Core/Alerts/AlertContracts.cs:AlertEvents.All`, `AlertConditions` | `alert_rules`, `alert_rule_webhooks`, `alert_states` | console Notifications page | provider-quota-refresh, subscription-account-refresh, token-limits-enforcement |
| Webhook delivery | One attempt to deliver a fired alert, with retries and backoff. | `src/Astra.Server/Alerts/WebhookDispatcher.cs:WebhookDispatcher` | `webhooks`, `webhook_deliveries` | console Notifications page | provider-quota-refresh |
| Plugin | A magpie-compatible extension: gateway middleware, an agent client, or a provider backend running on Bun. | `src/Astra.Core/Plugins/PluginContracts.cs:PluginEntry`, `PluginKinds` | `plugins`, `plugin_provider_prefs`; files under `~/.astra/plugins/` | console Plugins page, CLI `astra plugin` | plugin-install-and-run |
| Plugin spec | Where a plugin comes from: a path, a git URL or an npm package, resolving to a short name. | `src/Astra.Plugins/Store/PluginSpec.cs:PluginSpec`; `PluginSources` in Core | `plugins.source_json` | install dialog, CLI | plugin-install-and-run |
| Remote access / tunnel | A Cloudflare Tunnel (`cloudflared`) that exposes the gateway off-machine. Requests arriving through it are marked remote and lose most admin reach. | `src/Astra.Server/Tunnel/TunnelService.cs:TunnelService`; `src/Astra.Gateway/Http/RequestOrigin.cs:RequestOrigin` | tunnel settings in the `app` settings blob; process state in `~/.astra/tools/` | console Settings, remote access page | admin-api-request, server-startup |
| App settings | The single runtime-editable settings blob; adding a setting is a property plus endpoint/UI wiring, no migration. | `src/Astra.Core/AppSettings.cs:AppSettings` | `settings` row key `"app"` | console Settings page | server-startup |
| Data directory | `~/.astra` (override `ASTRA_HOME`): config, runtime file, database, plugins, tools. Layout defined in three places that must stay in sync. | `src/Astra.Core/AstraPaths.cs:AstraPaths`, `cli/src/lib/paths.ts`, `desktop/src/shared/paths.ts` | the filesystem | CLI, desktop, Docker volume | server-startup |
| Runtime file | What the server is *actually* running as: pid, port, apiVersion, runtime token. The port drifts, so this file — not `config.json` — is authoritative. | `src/Astra.Server/Hosting/RuntimeFile.cs:RuntimeFile` | `~/.astra/runtime.json` | CLI, desktop, `healthcheck` | server-startup |
| Update manifest | The feed document describing a release: version, apiVersion, notes, per-RID server url/sha256/size. | `packages/update-core/src/manifest.ts:UpdateManifest`, `scripts/gen-manifest.mjs` | served by the docs site under `${DATA_DIR}/client-releases/` | console Settings, desktop update banner, CLI | release-and-update |
| Update state | How far an applied update got, for resume and rollback. | `packages/update-core/src/state.ts:UpdateState` | `~/.astra/update-state.json` | desktop/CLI update output | release-and-update |
| Install info | Which server binary a client should use, and where it lives. | `packages/update-core/src/install-info.ts`, `cli/src/lib/install-json.ts`, `desktop/src/shared/install.ts` | `~/.astra/install.json` | CLI and desktop resolvers | release-and-update, server-startup |
| Plugin market listing | A catalog entry for installable plugins, served by the docs site. | `docs/lib/plugin-market/types.ts`, parsed by `src/Astra.Plugins/Market/PluginMarket.cs:PluginMarket` | registry JSON at `PluginMarket.DefaultUrl` + `${DATA_DIR}/plugin-market/` | console Plugins page, CLI search, the `/plugins` site pages | plugin-install-and-run |
